# Функции datetime

Начиная с версии DaJet Script версии 2.0.15, реализованы функции для работы с типом данных ```datetime```.

### Функции DATESTART и DATEEND

Функции **DATESTART** и **DATEEND** выполняют приведение, переданной в качестве параметра, даты к началу или концу указанного периода соответственно.

```SQL
DATESTART('<period>', <datetime>)
DATEEND('<period>', <datetime>)
```

- **\<period\>** - значение периода, к началу которого необходимо привести дату
- **\<datetime\>** - значение даты, которую необходимо привести к указанному периоду

> **Важно!** Значение параметра \<period\> является строковым значением в **верхнем** регистре.

| Пример | Результат |
|--------|-----------|
| **DATESTART** ( 'YEAR' , '2026-03-01T12:34:56' ) | ```2026-01-01 00:00:00``` |
| **DATESTART** ( 'QUARTER' , '2026-05-01T12:34:56' ) | ```2026-04-01 00:00:00``` |
| **DATESTART** ( 'MONTH' , '2026-03-05T12:34:56' ) | ```2026-03-01 00:00:00``` |
| **DATESTART** ( 'DAY' , '2026-03-01T12:34:56' ) | ```2026-03-01 00:00:00``` |
| **DATESTART** ( 'HOUR' , '2026-03-01T12:34:56' ) | ```2026-03-01 12:00:00``` |
| **DATESTART** ( 'MINUTE' , '2026-03-01T12:34:56' ) | ```2026-03-01 12:34:00``` |

| Пример | Результат |
|--------|-----------|
| **DATEEND** ( 'YEAR' , '2026-03-01T12:34:56' ) | ```2026-12-31 23:59:59``` |
| **DATEEND** ( 'QUARTER' , '2026-05-01T12:34:56' ) | ```2026-06-30 23:59:59``` |
| **DATEEND** ( 'MONTH' , '2026-03-05T12:34:56' ) | ```2026-03-31 23:59:59``` |
| **DATEEND** ( 'DAY' , '2026-03-01T12:34:56' ) | ```2026-03-01 23:59:59``` |
| **DATEEND** ( 'HOUR' , '2026-03-01T12:34:56' ) | ```2026-03-01 12:59:59``` |
| **DATEEND** ( 'MINUTE' , '2026-03-01T12:34:56' ) | ```2026-03-01 12:34:59``` |

### Функция DATEADD

Функция **DATEADD** выполняет добавление или вычитание указанного количества периодов к дате, переданной в качестве параметра.

```SQL
DATEADD('<period>', <count>, <datetime>)
```

- **\<period\>** - период для добавления или вычитания из указанной даты
- **\<count\>** - количество периодов для добавления или вычитания из указанной даты
- **\<datetime\>** - значение даты, которую необходимо уменьшить или увеличить на указанное количество периодов

> **Важно!** Значение параметра \<period\> является строковым значением в **верхнем** регистре.

> **Внимание!** Для вычитания используется отрицательное значение параметра \<count\>.

| Пример | Результат |
|--------|-----------|
| **DATEADD** ( 'YEAR' , 1 , '2026-01-01T00:00:00' ) | ```2027-01-01 00:00:00``` |
| **DATEADD** ( 'QUARTER' , 1 , '2026-01-01T00:00:00' ) | ```2026-04-01 00:00:00``` |
| **DATEADD** ( 'MONTH' , 1 , '2026-01-01T00:00:00' ) | ```2026-02-01 00:00:00``` |
| **DATEADD** ( 'DAY' , 1 , '2026-01-01T00:00:00' ) | ```2026-01-02 00:00:00``` |
| **DATEADD** ( 'HOUR' , 1 , '2026-01-01T00:00:00' ) | ```2026-01-01 01:00:00``` |
| **DATEADD** ( 'MINUTE' , 1 , '2026-01-01T00:00:00' ) | ```2026-01-01 00:01:00``` |
| **DATEADD** ( 'SECOND' , 1 , '2026-01-01T00:00:00' ) | ```2026-01-01 00:00:01``` |

| Пример | Результат |
|--------|-----------|
| **DATEADD** ( 'YEAR' , -1 , '2026-01-01T00:00:00' ) | ```2025-01-01 00:00:00``` |
| **DATEADD** ( 'QUARTER' , -1 , '2026-01-01T00:00:00' ) | ```2025-10-01 00:00:00``` |
| **DATEADD** ( 'MONTH' , -1 , '2026-01-01T00:00:00' ) | ```2025-12-01 00:00:00``` |
| **DATEADD** ( 'DAY' , -1 , '2026-01-01T00:00:00' ) | ```2025-12-31 00:00:00``` |
| **DATEADD** ( 'HOUR' , -1 , '2026-01-01T00:00:00' ) | ```2025-12-31 23:00:00``` |
| **DATEADD** ( 'MINUTE' , -1 , '2026-01-01T00:00:00' ) | ```2025-12-31 23:59:00``` |
| **DATEADD** ( 'SECOND' , -1 , '2026-01-01T00:00:00' ) | ```2025-12-31 23:59:59``` |

### Пример использования функций ```datetime```

```SQL
DECLARE @Период datetime  = '2026-03-01T12:34:56'

PRIVATE @АктуальныеИтоги datetime = '3999-11-01T00:00:00'
PRIVATE @Результат       object
PRIVATE @Таблица         array

SET @Результат.ВходнойПараметр  = @Период
SET @Результат.НачалоМесяца     = DATESTART('MONTH', @Период)
SET @Результат.КонецМесяца      = DATEEND  ('MONTH', @Период)
SET @Результат.ПлюсМесяц        = DATEADD('MONTH',  1, @Период)
SET @Результат.НачалоПлюсМесяц  = DATEADD('MONTH',  1, DATESTART('MONTH', @Период))
SET @Результат.МинусМесяц       = DATEADD('MONTH', -1, @Период)
SET @Результат.НачалоМинусМесяц = DATEADD('MONTH', -1, DATESTART('MONTH', @Период))

USE 'MS_TEST'

  SELECT Период, Номенклатура, Количество
    INTO @Таблица
    FROM РегистрНакопления.ОстаткиТовара.Итоги
   WHERE Период IN (@АктуальныеИтоги, @Результат.НачалоМесяца, @Результат.НачалоПлюсМесяц)
   ORDER BY Период ASC

END

SET @Результат.Таблица = @Таблица

RETURN @Результат
```
