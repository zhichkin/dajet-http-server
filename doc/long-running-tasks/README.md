# Выполнение длительных скриптов хостом DaJet

Для управления выполнением скриптов можно использовать специальные директивы хоста DaJet:
- **STARTUP** (запуск скрипта при старте хоста DaJet);
- **LONG_TASK** (выделение отдельного потока выполнения операционной системы);
- **SINGLETON** (выполнение единственного экземпляра скрипта).

> **Внимание!** Директива ```SINGLETON``` параметризуется строковой константой, значение которой должно быть уникальным в переделах хоста. Именно по этому значению хост DaJet контролирует выполнение единственного экземпляра скрипта.

**Пример длительно выполняющегося скрипта**

```SQL
# STARTUP                    -- Запуск скрипта при старте хоста DaJet
# LONG_TASK                  -- Долгий скрипт (отдельный поток выполнения)
# SINGLETON 'LONG TASK TEST' -- Директива контроля единственного выполнения

PRIVATE @Счётчик integer

PRINT '[LONG TASK TEST] START'

WHILE @Счётчик < 10

  SET @Счётчик = @Счётчик + 1

  IF @Счётчик = 5 THEN BREAK END

  PRINT 'LOOP: ' + @Счётчик

  SLEEP 10

END

PRINT '[LONG TASK TEST] END'
```

**Результат выполнения скрипта**

```
[LONG TASK TEST] START
LOOP: 1
LOOP: 2
LOOP: 3
LOOP: 4
[LONG TASK TEST] END
```
