# Настройка обмена между базами данных

Ниже следующий пример демонстрирует выполнение "вечного" скрипта DaJet, обеспечивающего непрерывный обмен сообщениями между двумя базами данных. Особенности выполнения:
- один раз в секунду скрипт опрашивает базу-источник о наличии сообщений для базы-приёмника;
- при наличии сообщений выполняется их отправка в строгом порядке нумерации в базе-источнике;
- исходящее сообщение удаляется только в том случае, если отправка была выполнена успешно;
- успешной отправкой считается фактическая запись сообщения во входящий регистр базы-приёмника.

Таким образом скрипт реализует ```at least once in order```: гарантированную доставку сообщений в порядке их нумерации источником.

Для организации обмена между двумя базами данных необходимо выполнить следующие действия:

1. В базе-источнике создать независимый непериодический регистр сведений "ИсходящаяОчередь", имеющий следующую структуру:

|Назначение|Имя|Тип данных|
|----------|---|----------|
|Измерение|НомерСообщения|Число(15,0)|
|Ресурс|Отправитель|Строка(36)|
|Ресурс|Получатель|Строка(36)|
|Ресурс|ТипСообщения|Строка(1024)|
|Ресурс|ТелоСообщения|Строка(0)|

2. В базе-приёмнике создать независимый непериодический регистр сведений "ВходящаяОчередь", имеющий следующую структуру:

|Назначение|Имя|Тип данных|
|----------|---|----------|
|Измерение|НомерСообщения|Число(15,0)|
|Ресурс|Отправитель|Строка(36)|
|Ресурс|ТипСообщения|Строка(1024)|
|Ресурс|ТелоСообщения|Строка(0)|
|Реквизит|ВремяПолучения|Дата и время|

3. Опубликовать скрипт обмена данными в каталог ```api``` хоста DaJet.

```SQL

# LONG_TASK
# SINGLETON 'Обмен данными MS-PG'

PRIVATE @Счётчик integer
PRIVATE @Сообщение object

WHILE TRUE

   TRY

      USE TRANSACTION 'MS_TEST'

         CONSUME TOP 1000 НомерСообщения
               , Отправитель, Получатель
               , ТипСообщения, ТелоСообщения
            INTO @Сообщение
            FROM РегистрСведений.ИсходящаяОчередь
           ORDER BY НомерСообщения ASC

         USE 'PG_TEST'
            INSERT РегистрСведений.ВходящаяОчередь
            SELECT НомерСообщения = @Сообщение.НомерСообщения
                 , ДатаВремя      = NOW()
                 , Отправитель    = @Сообщение.Отправитель
                 , ТипСообщения   = @Сообщение.ТипСообщения
                 , ТелоСообщения  = @Сообщение.ТелоСообщения
         END

         SET @Счётчик = @Счётчик + 1
      END

   CATCH
      PRINT '[Обмен данными MS-PG] ' + ERROR_MESSAGE()
   END

   PRINT '[Обмен данными MS-PG] Consumed ' + @Счётчик + ' messages.'

   SLEEP 1

END -- WHILE
```

4. Запустить скрипт обмена данными.

5. Проверить выполнение скрипта хостом DaJet.

6. В базе-источнике записать сообщение в исходящий регистр.

7. В базе-приёмнике проверить появление сообщения во входящем регистре.

8. Остановить выполнение скрипта хостом DaJet.
