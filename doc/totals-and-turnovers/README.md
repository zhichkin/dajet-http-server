# Остатки и обороты регистров накопления

В языке запросов DaJet реализован доступ к системным таблицам регистров накопления "Настройки" и "Итоги".

Этот функционал необходим для реализации логики виртуальных таблиц "Остатки", "Обороты" и "ОстаткиИОброты".

> Ниже следующие примеры запросов представлены в терминах DaJet Script для наглядности. Суть и точность алгоритмов платформы это не искажает. Оригинальные алгоритмы платформы получены при помощи трассировки запросов СУБД.

Для использования таблиц итогов необходимо выполнение двух условий:
1. Для регистра должен быть включён режим использование итогов.
2. Должен быть установлен период для расчёта и хранения итогов.

Начальное состояние таблицы настроек выглядит следующим образом:

| RegID | UseTotals | ActualPeriod | MinCalculatedPeriod | Period | UseSplitter |
|------------------------------------|---|------|---------------------|---------------------|------|
| 0xA97EF36FC863734B81346E052FD75FC5 | 0 | 0x01 | 2001-01-01 00:00:00 | 2001-01-01 00:00:00 | 0x01 |

- **RegID** - Внутренний идентификатор объекта метаданных
- **UseTotals** - Флаг включения режима использования итогов (0 - включено, 1 - выключено)
- **ActualPeriod** - Флаг включения расчёта актуальных итогов (0x01 - включено, 0x00 - выключено)
- **MinCalculatedPeriod** - Минимальный период хранимых итогов (по умолчанию не установлен)
- **Period** - Максимальный период хранимых итогов (по умолчанию не установлен)
- **UseSplitter** - Флаг использования разделителя итогов (0x01 - включено, 0x00 - выключено)

> Значение настройки разделителя итогов не влияет на расчёт и алгоритмы использования итогов.

По умолчанию, для вновь созданного регистра накопления, включены все режимы итогов. Однако фактическое использование таблиц итогов запросами получения остатков реализуется платформой только после установки периода расчитанных хранимых или актуальных итогов. До тех пор, пока это не будет сделано, запросы выполняются только к основной таблице движений регистра.

После установки периода хранимых итогов, приведённого в качестве примера на картинке выше, таблица настроек будет выглядеть следующим образом:

| RegID | UseTotals | ActualPeriod | MinCalculatedPeriod | Period | UseSplitter |
|------------------------------------|---|------|---------------------|---------------------|------|
| 0xA97EF36FC863734B81346E052FD75FC5 | 0 | 0x01 | 4026-03-01 00:00:00 | 4026-04-01 00:00:00 | 0x01 |

Получить текущие настройки регистра можно следующим образом:

```SQL
PRIVATE @Настройки object

USE 'MS_TEST'

  SELECT UseTotals           -- numeric(1,0) Использовать итоги
       , ActualPeriod        -- boolean      Использовать актуальные итоги
       , MinCalculatedPeriod -- datetime     Минимальный период хранимых итогов
       , Period              -- datetime     Максимальный период хранимых итогов
       , UseSplitter         -- boolean      Использовать разделение итогов       
    INTO @Настройки
    FROM РегистрНакопления.ОстаткиТовара.Настройки

END

RETURN @Настройки

-- Результат выполнения скрипта
-- {
--   "UseTotals": 0,
--   "ActualPeriod": true,
--   "MinCalculatedPeriod": "2026-03-01T00:00:00",
--   "Period": "2026-04-01T00:00:00",
--   "UseSplitter": true
-- }
```

Установка режима использования итогов и периода хранения выполняет процедуру пересчёта итогов за указанный период. Итоги расчитываются по основной таблице движений регистра. Например, имея следующую таблицу движений регистра,

| Период | Регистратор (тип) | Регистратор (ссылка) | Номер строки | Активность | Вид движения | Номенклатура | Количество |
|--------|-------------------|----------------------|--------------|------------|--------------|--------------|------------|
| 4026-02-15<br>&nbsp;&nbsp;&nbsp;00:00:00&nbsp;&nbsp;&nbsp; | 0x00000038 | 0x99F788B1112C8F1B11F196564BE2C9E5 | 1 | 0x01 | 0 | 0x99F788B1112C8F1B11F195767D5EAB72 | 1 |
| 4026-03-01<br>&nbsp;&nbsp;&nbsp;00:00:00&nbsp;&nbsp;&nbsp; | 0x00000038 | 0x99F788B1112C8F1B11F19656CF5D7A37 | 1 | 0x01 | 0 | 0x99F788B1112C8F1B11F195767D5EAB72 | 1 |
| 4026-03-15<br>&nbsp;&nbsp;&nbsp;00:00:00&nbsp;&nbsp;&nbsp; | 0x00000038 | 0x99F788B1112C8F1B11F19657059379CA | 1 | 0x01 | 0 | 0x99F788B1112C8F1B11F195767D5EAB72 | 1 |
| 4026-04-01<br>&nbsp;&nbsp;&nbsp;00:00:00&nbsp;&nbsp;&nbsp; | 0x00000038 | 0x99F788B1112C8F1B11F19657384265FB | 1 | 0x01 | 0 | 0x99F788B1112C8F1B11F195767D5EAB72 | 1 |
| 4026-04-15<br>&nbsp;&nbsp;&nbsp;00:00:00&nbsp;&nbsp;&nbsp; | 0x00000038 | 0x99F788B1112C8F1B11F196588AA65232 | 1 | 0x01 | 0 | 0x99F788B1112C8F1B11F195767D5EAB72 | 1 |

после выполнения процедуры пересчёта итогов таблица итогов будет иметь следующий вид, где дата ```5999-11-01 00:00:00``` является константой и отображает актуальные итоги.

| Период | Номенклатура | Количество | Splitter |
|--------|--------------|------------|----------|
| 4026-03-01 00:00:00 | 0x99F788B1112C8F1B11F195767D5EAB72 | 1 | 0 |
| 4026-04-01 00:00:00 | 0x99F788B1112C8F1B11F195767D5EAB72 | 3 | 0 |
| 5999-11-01 00:00:00 | 0x99F788B1112C8F1B11F195767D5EAB72 | 5 | 0 |

Для лучшего понимания того, каким образом платформа выполняет пересчёт итогов, ниже приводится соответствующий запрос. Запрос пересчёта итогов выполняется для каждого месяца, входящего в указанный период. Каждый месяц пересчитывается в отдельной транзакции. По завершении транзакции для первого месяца периода выполняется обновление поля MinCalculatedPeriod таблицы настроек регистра. Обновление поля Period выполняется для всех месяцев пересчёта.

```SQL
DECLARE @НачалоПериода datetime = '4026-03-01 00:00:00'
DECLARE @КонецПериода  datetime = '4026-04-01 00:00:00'

INSERT РегистрНакопления.ОстаткиТовара.Итоги (Период, Номенклатура, Количество, Splitter)
SELECT @КонецПериода, ИтогиИДвижения.Номенклатура, SUM(ИтогиИДвижения.Количество), 0.0
  FROM (SELECT Номенклатура = Итоги.Номенклатура
             , Количество   = Итоги.Количество
          FROM РегистрНакопления.ОстаткиТовара.Итоги AS Итоги
         WHERE Итоги.Период = @НачалоПериода
        UNION ALL
        SELECT Номенклатура = Движения.Номенклатура
             , Количество   = CASE WHEN Движения.ВидДвижения = 0.0
                                   THEN  Движения.Количество
                                   ELSE -Движения.Количество END
          FROM РегистрНакопления.ОстаткиТовара AS Движения
         WHERE Движения.Активность = TRUE
           AND Движения.Период >= @НачалоПериода
           AND Движения.Период < @КонецПериода) AS ИтогиИДвижения
 GROUP BY ИтогиИДвижения.Номенклатура
HAVING SUM(ИтогиИДвижения.Количество) <> 0.0

-- Обновление настроек регистра накопления
UPDATE РегистрНакопления.ОстаткиТовара.Настройки SET MinCalculatedPeriod = @НачалоПериода WHERE RegID = 0xA97EF36FC863734B81346E052FD75FC5
UPDATE РегистрНакопления.ОстаткиТовара.Настройки SET Period              = @КонецПериода  WHERE RegID = 0xA97EF36FC863734B81346E052FD75FC5
```

## Остатки

Рассмотрим запросы, генерируемые платформой, для получения остатков.

**Итоги не используются**

В данном случае использование итогов отключено или не установлен период хранимых итогов, а также не включены актуальные итоги.

Расчёт выполняется по основной таблице движений регистра накопления без включения периода отчёта, указанного как дата, на которую необходимо получить остатки.

```SQL
DECLARE @ПериодИтогов datetime = '2001-01-01 00:00:00' -- Хранимые итоги не расчитаны (пустая дата)
DECLARE @ПериодОтчёта datetime = '4026-03-01 00:00:00' -- Период отчёта, на который нужно получить остатки

SELECT Номенклатура
     , Остаток = SUM(CASE WHEN ВидДвижения = 0.0 THEN Количество ELSE -Количество END)
  FROM РегистрНакопления.ОстаткиТовара
 WHERE Активность = TRUE AND Период < @ПериодОтчёта
 GROUP BY Номенклатура
HAVING SUM(CASE WHEN ВидДвижения = 0.0 THEN Количество ELSE -Количество END) <> 0.0
```

**Используется только таблица итогов**

Использование итогов включено, установлен период хранимых итогов, а также период отчёта совпадает с началом месяца, который входит в период расчитанных итогов. Это идеальный с точки зрения производительности вариант отчёта. В данном случае следует обратить внимание на использование агрегатной функции ```SUM``` - это учитывает возможное использование разделителя итогов.

```SQL
DECLARE @ПериодИтогов datetime = '4026-03-01 00:00:00' -- Итоги расчитаны и совпадают с периодом отчёта
DECLARE @ПериодОтчёта datetime = '4026-03-01 00:00:00' -- Период отчёта, на который нужно получить остатки

SELECT Номенклатура, Остаток = SUM(Количество)
  FROM РегистрНакопления.ОстаткиТовара.Итоги
 WHERE Период = @ПериодИтогов
 GROUP BY Номенклатура
HAVING SUM(Количество) <> 0.0
```

**Используется таблица итогов без актуальных итогов**

Использование итогов включено, установлен период хранимых итогов, актуальные итоги выключены, период отчёта больше максимального периода хранимых итогов.

В данном случае алгоритм запроса таков: сначала получаются хранимые итоги максимального периода, затем расчитываются движения за период между максимальным периодом хранимых итогов и периодом отчёта, на который нужно получить остатки, результаты двух выборок складываются.

```SQL
DECLARE @ПериодИтогов datetime = '4026-04-01 00:00:00' -- Максимальный период хранимых итогов
DECLARE @ПериодОтчёта datetime = '4026-05-15 00:00:00' -- Период отчёта, на который нужно получить остатки

SELECT Номенклатура = ИтогиИДвижения.Номенклатура
     , Остаток      = SUM(ИтогиИДвижения.Количество)
  FROM (SELECT Номенклатура = Итоги.Номенклатура
             , Количество   = SUM(Итоги.Количество)
          FROM РегистрНакопления.ОстаткиТовара.Итоги AS Итоги
         WHERE Период = @ПериодИтогов
         GROUP BY Итоги.Номенклатура
        HAVING SUM(Итоги.Количество) <> 0.0
        UNION ALL
        SELECT Номенклатура = Движения.Номенклатура
             , Количество   = SUM(CASE WHEN Движения.ВидДвижения = 0.0
                                       THEN  Движения.Количество
                                       ELSE -Движения.Количество END)
          FROM РегистрНакопления.ОстаткиТовара AS Движения
         WHERE Движения.Активность = TRUE
           AND Движения.Период >= @ПериодИтогов
           AND Движения.Период < @ПериодОтчёта
         GROUP BY Движения.Номенклатура
        HAVING SUM(CASE WHEN Движения.ВидДвижения = 0.0
                        THEN  Движения.Количество
                        ELSE -Движения.Количество END) <> 0.0) AS ИтогиИДвижения
 GROUP BY ИтогиИДвижения.Номеклатура
HAVING SUM(ИтогиИДвижения.Количество) <> 0.0
```

**Используется таблица итогов и движения**

Использование итогов включено, установлен период хранимых итогов, актуальные итоги тоже включены, период отчёта любой, кроме случая когда он совпадает с началом месяца, который входит в период расчитанных итогов.

Алгоритм получения остатков для всех значений периода отчёта одинаковый:
- Получаем ближайшие, следующие после периода отчёта, хранимые итоги.
- Получаем движения за период между периодом отчёта и хранимыми итогами первого шага.
- Движения **вычитаем** из хранимых итогов.

В данном случае периодом хранимых итогов будет либо период расчитанных хранимых итогов, либо период актуальных итогов.

```SQL
DECLARE @ПериодИтогов datetime = '4026-03-01 00:00:00' -- Первый, следующий после периода отчёта, период хранимых или актуальных итогов
DECLARE @ПериодОтчёта datetime = '4026-02-15 00:00:00' -- Период отчёта, на который нужно получить остатки

SELECT Номенклатура = ИтогиИДвижения.Номенклатура
     , Остаток      = SUM(ИтогиИДвижения.Количество)
  FROM (SELECT Номенклатура = Итоги.Номенклатура
             , Количество   = SUM(Итоги.Количество)
          FROM РегистрНакопления.ОстаткиТовара.Итоги AS Итоги
         WHERE Период = @ПериодИтогов
         GROUP BY Итоги.Номенклатура
        HAVING SUM(Итоги.Количество) <> 0.0
        UNION ALL
        SELECT Номенклатура = Движения.Номенклатура
             , Количество   = SUM(CASE WHEN Движения.ВидДвижения = 0.0
                                       THEN -Движения.Количество
                                       ELSE  Движения.Количество END)
          FROM РегистрНакопления.ОстаткиТовара AS Движения
         WHERE Движения.Активность = TRUE
           AND Движения.Период >= @ПериодОтчёта
           AND Движения.Период < @ПериодИтогов
         GROUP BY Движения.Номенклатура
        HAVING SUM(CASE WHEN Движения.ВидДвижения = 0.0
                        THEN -Движения.Количество
                        ELSE  Движения.Количество END) <> 0.0) AS ИтогиИДвижения
 GROUP BY ИтогиИДвижения.Номенклатура
HAVING SUM(ИтогиИДвижения.Количество) <> 0.0
```

## Получение остатков при помощи DaJet Script

```SQL
DECLARE @ПериодОтчёта     datetime = '2026-02-16T00:00:00' -- Период отчёта, на который нужно получить остатки
DECLARE @ПериодИтогов     datetime = '2026-03-01T00:00:00' -- Период хранимых итогов для данного периода отчёта
PRIVATE @ПустойПериод     datetime = '0001-01-01T00:00:00'
PRIVATE @АктуальныйПериод datetime = '3999-11-01T00:00:00' -- Период актуальных итогов (константа)

PRIVATE @Результат array
PRIVATE @Настройки object

USE 'MS_TEST'

  SELECT UseTotals           -- numeric(1,0) Использовать итоги
       , ActualPeriod        -- boolean      Использовать актуальные итоги
       , MinCalculatedPeriod -- datetime     Минимальный период хранимых итогов
       , Period              -- datetime     Максимальный период хранимых итогов       
    INTO @Настройки
    FROM РегистрНакопления.ОстаткиТовара.Настройки

  -- Итоги не используются, период хранимых итогов не установлен и не используются актуальные итоги
  IF @Настройки.UseTotals = 1 OR (@Настройки.UseTotals = 0 AND @Настройки.MinCalculatedPeriod = @ПустойПериод AND @Настройки.ActualPeriod = FALSE) THEN

     SELECT Номенклатура
          , Остаток = SUM(CASE WHEN ВидДвижения = 0.0 THEN Количество ELSE -Количество END)
       INTO @Результат
       FROM РегистрНакопления.ОстаткиТовара
      WHERE Активность = TRUE AND Период < @ПериодОтчёта
      GROUP BY Номенклатура
     HAVING SUM(CASE WHEN ВидДвижения = 0.0 THEN Количество ELSE -Количество END) <> 0.0

     RETURN @Результат
  END

  -- Использование итогов включено, период хранимых итогов установлен и период отчёта совпадает с периодом хранимых итогов
  IF @ПериодОтчёта >= @Настройки.MinCalculatedPeriod AND @ПериодОтчёта <= @Настройки.Period AND @ПериодОтчёта = @ПериодИтогов THEN

     SELECT Номенклатура, Остаток = SUM(Количество)
      INTO @Результат
      FROM РегистрНакопления.ОстаткиТовара.Итоги
     WHERE Период = @ПериодИтогов
     GROUP BY Номенклатура
    HAVING SUM(Количество) <> 0.0

     RETURN @Результат
  END

  -- Использование итогов включено, период хранимых итогов установлен, актуальные итоги не используются
  IF @Настройки.Period > @ПустойПериод AND @Настройки.ActualPeriod = FALSE AND @ПериодОтчёта > @Настройки.Period THEN

     SELECT Номенклатура = ИтогиИДвижения.Номенклатура
          , Остаток      = SUM(ИтогиИДвижения.Количество)
       INTO @Результат
       FROM (SELECT Номенклатура = Итоги.Номенклатура
                  , Количество   = SUM(Итоги.Количество)
               FROM РегистрНакопления.ОстаткиТовара.Итоги AS Итоги
              WHERE Период = @ПериодИтогов
              GROUP BY Итоги.Номенклатура
             HAVING SUM(Итоги.Количество) <> 0.0
             UNION ALL
             SELECT Номенклатура = Движения.Номенклатура
                  , Количество   = SUM(CASE WHEN Движения.ВидДвижения = 0.0
                                            THEN  Движения.Количество
                                            ELSE -Движения.Количество END)
               FROM РегистрНакопления.ОстаткиТовара AS Движения
              WHERE Движения.Активность = TRUE
                AND Движения.Период >= @ПериодИтогов
                AND Движения.Период < @ПериодОтчёта
              GROUP BY Движения.Номенклатура
             HAVING SUM(CASE WHEN Движения.ВидДвижения = 0.0
                             THEN  Движения.Количество
                             ELSE -Движения.Количество END) <> 0.0) AS ИтогиИДвижения
      GROUP BY ИтогиИДвижения.Номенклатура
     HAVING SUM(ИтогиИДвижения.Количество) <> 0.0

     RETURN @Результат
  END

  -- Использование итогов включено, период хранимых итогов не установлен, но используются актуальные итоги
  IF @Настройки.MinCalculatedPeriod = @ПустойПериод AND @Настройки.ActualPeriod = TRUE THEN
     SET @ПериодИтогов = @АктуальныйПериод
  END

  -- Использование итогов включено, установлен период хранимых итогов,
  -- период отчёта больше максимального периода хранимых итогов,
  -- использование актуальных итогов включено
  IF @ПериодОтчёта > @Настройки.Period AND @Настройки.ActualPeriod = TRUE THEN
     SET @ПериодИтогов = @АктуальныйПериод
  END

  -- Использование итогов включено, установлен период хранимых итогов,
  -- период отчёта меньше минимального периода хранимых итогов
  IF @ПериодОтчёта < @Настройки.MinCalculatedPeriod THEN
     SET @ПериодИтогов = @Настройки.MinCalculatedPeriod
  END

  PRINT 'Период итогов: ' + @ПериодИтогов
  PRINT 'Период отчёта: ' + @ПериодОтчёта

  SELECT Номенклатура = ИтогиИДвижения.Номенклатура
       , Остаток      = SUM(ИтогиИДвижения.Количество)
    INTO @Результат
    FROM (SELECT Номенклатура = Итоги.Номенклатура
               , Количество   = SUM(Итоги.Количество)
            FROM РегистрНакопления.ОстаткиТовара.Итоги AS Итоги
           WHERE Период = @ПериодИтогов
           GROUP BY Итоги.Номенклатура
          HAVING SUM(Итоги.Количество) <> 0.0
          UNION ALL
          SELECT Номенклатура = Движения.Номенклатура
               , Количество   = SUM(CASE WHEN Движения.ВидДвижения = 0.0
                                         THEN -Движения.Количество
                                         ELSE  Движения.Количество END)
            FROM РегистрНакопления.ОстаткиТовара AS Движения
           WHERE Движения.Активность = TRUE
             AND Движения.Период >= @ПериодОтчёта
             AND Движения.Период < @ПериодИтогов
           GROUP BY Движения.Номенклатура
          HAVING SUM(CASE WHEN Движения.ВидДвижения = 0.0
                          THEN -Движения.Количество
                          ELSE  Движения.Количество END) <> 0.0) AS ИтогиИДвижения
   GROUP BY ИтогиИДвижения.Номенклатура
  HAVING SUM(ИтогиИДвижения.Количество) <> 0.0

  RETURN @Результат

END -- USE
```
